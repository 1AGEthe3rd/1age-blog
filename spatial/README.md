# Spatial Design 013 — Global publishing
Walkable cosmic media center: Global Publications, Independent Voices, Writer Studio, Official 1AGE. Existing publications.json read/search and existing archive permalinks preserved. Draft editor is memory-only; no submission, persistent accounts or public independent articles yet.
Open to independent writers, journalists, businesses and projects across all subjects. Page identity and verified publisher profiles, author ownership, revisions, attribution, editorial labeling, search and geographic discovery are future work. Forum discussions can reference stable article IDs; separate long-form publishing from discussion threads. Implement consent, moderation/reporting, copyright handling, block controls, publishing authorization and privacy before public participation. No paid content or rewards enabled.
Uses existing blog's pinned Three.js CDN dependency and local gamepad/logo; Earth texture references pinned first-party Quest repository asset. Network and CORS are not verified; bundle dependencies for release. All existing production files preserved. Browser/mobile/controller and visual checks pending. No deployment.
